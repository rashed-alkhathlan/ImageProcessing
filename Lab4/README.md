# Lab 4

This lab covers fixed thresholding, contrast stretching, histogram equalization, and histogram matching. It includes the procedural tasks and all three assessment tasks from the Lab 4 manual.

Run `Lab4.ipynb` from this folder. `Lab4.pdf` contains the notebook code and saved results.

The manual's `Parrot.png` was not supplied, so thresholding uses `cameraman.tif` from the existing lab images. The moon, rocket, and Chelsea images come from `skimage.data`; copies are included in this folder as `moon.png`, `rocket.png`, and `chelsea.png`.

References from the manual: [Histogram equalization](https://scikit-image.org/docs/stable/auto_examples/color_exposure/plot_equalize.html) and [Histogram matching](https://scikit-image.org/docs/0.24.x/auto_examples/color_exposure/plot_histogram_matching.html).
