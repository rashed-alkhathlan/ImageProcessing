# Lab 7

This lab covers Laplacian sharpening and mathematical and statistical filters for image denoising. `Lab_7_(A)_Laplacian_Filter.ipynb` demonstrates manual and OpenCV Laplacian filters. `Lab_7_(B)_Maths_&_Statistics_Filters.ipynb` explores noise models and arithmetic, geometric, harmonic, contra-harmonic, median, max, min, and midpoint filters.

The notebooks load `moon.jpg` and `noise.jpg`; `salt&Pepper.jpg` is also included. Run either notebook from this folder.
